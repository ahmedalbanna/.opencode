Read `.agents/docs/templates/feature-template.md`.

Create a new documentation file for the feature "{feature-name}" in the appropriate location:
- Backend feature: `{backend}/docs/modules/{feature-name}.md`
- Frontend feature: `{frontend}/docs/features/{feature-name}.md`

Fill ALL sections of the template:
- Description
- User Stories / Use Cases (at least 2)
- API Endpoints Used (table with Method, Path, Description, Request Body, Response)
- Technical Implementation (Backend + Flutter + React sections)
- State Management Details
- Testing
- References

Generate the complete documentation file.
